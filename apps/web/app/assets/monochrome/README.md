# AITVHot monochrome assets

SVG assets are original exports from the approved [Figma design](https://www.figma.com/design/mJTwTbPeIkKo2vI63yvnNe?node-id=2-35). They retain their original SVG geometry and intrinsic dimensions. The UI applies theme inversion to the exported monochrome strokes. Content images continue to come from the publication API.

Fonts are self-hosted WOFF2 subsets, including Latin and Chinese glyph coverage for dynamic headlines:

- Noto Sans SC regular and bold, from the repository's `assets/og-fonts` sources. See `noto-sans-LICENSE`.
- Noto Serif SC bold, from Google Fonts, instantiated at weight 700. See `noto-serif-OFL.txt`.
- IBM Plex Mono regular, from Google Fonts. See `ibm-plex-OFL.txt`.

These assets have no runtime dependency on Figma or a third-party font service.
