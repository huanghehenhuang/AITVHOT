# 全部动态的重复报道折叠

2026-10-16：全部动态、标题摘要搜索、全文相关搜索现在按已确认的 fact 归组，一组只展示一个代表条目；其他报道通过现有的“另有 N 家信源报道”展开，原文和单篇页面保留。计数和分页在折叠后计算，搜索只从匹配条件的成员中选代表，防止匹配报道被不匹配的代表遮掉。

仅 primary/report 事实成员参与，mention、未归组内容和现有独立展示例外保留。不会根据相同标题删除教程或不同项目版本。不修改历史归属、不删除文章、不调整评分门槛，不改变 v1 全量材料接口。

## 核对

- 真实数据库同次核对：1901 个可展示材料，折叠后 1837 个条目；46 页共 1837 个不同文章 ID，跨页重复 0；33 个条目可展开其他报道。采集继续运行，数量会变化。
- 相关回归 18/18：分页、总数、当天数量、两种搜索、仅匹配非默认代表、mention、撤稿及精选代表。类型检查、Web 构建和站点 smoke 通过。
- 完整后端检查首次运行 779 项，759 通过、20 失败。其中 seats 原先断言全部动态逐篇展示，与本次行为冲突，已更新并在相关回归通过；其余 19 项属于已有的 Windows 备份、行业示例、页面元数据等失败。
- 构建后独立运行 Web 检查：54 项，37 通过、17 因本机缺少 Playwright Chromium 失败。构建与测试首次并行导致的构建目录读取失败不计为最终结果。
- 本机 API 与 Web 已重启，接口确认返回折叠结果，重启后 smoke 通过。

## 剩余边界

历史资料按现有规则不自动创建事件；未被确认成同一 fact 的跨源、跨语言重复仍会单独展示。不能将本次展示修复视为全部存量新闻已完成语义去重。后续应先核对真实漏归组样本，再做可审计的归属修正。
