## 核验与筛选

博客园、个人博客和 note 使用公开原生 RSS/Atom。综合博客、技术分享和创作者混合内容加创作关键词；note 补充日文的图像生成、视频生成和图像编辑表达。订阅的回补上限为 5 条，项目版本为 3 条；后续发现窗口沿用既有逻辑，不重置游标。均设置近 30 天上限与固定出版下界。

Monster 的原生 RSS 返回空列表，因此改采公开论坛主题页。只读 normalthread 正文主题，避开置顶广告与侧栏；日期来自主题作者旁的首次发帖时间，采用 +08:00，5 个原帖日期核对一致，不使用最后回复时间。加创作主题筛选以排除通用 NLP 等内容。

项目发布使用 GitHub 官方发布网页的 released this 日期，不使用提交或最近推送时间。按项目根地址和来源身份去重，未调用匿名限额 API。open-ai-canvas 的仓库确认 MIT；另两个项目本轮未从仓库页面取得足够明确的标准开源许可证据，保守标为“公开创作工具发布”，不声称可自由商用。
