Lead:

> This site aggregates public sources and uses a model to write Chinese summaries and picks. Copyright in the originals stays with each source. The site, RSS, public API and MCP can all be used without an account.

## 1. Content and copyright

Titles, summaries and the “why it matters” line are generated by a model from public sources and may be wrong. Check the original for anything important. Copyright in the originals stays with each source. Full text is shown on the site only when the source allows it; otherwise you get a summary and a link.

## 2. Corrections and takedowns

If you are a source and want a correction, a takedown, or a different presentation, contact us through the feedback page. We will handle it as soon as we can.

## 3. Using this site's data

State what you allow (for example personal reading, use inside an organisation) and what needs your permission first (for example a commercial product, public republication, bulk redistribution).

## 4. APIs and rate

RSS, the public API and MCP are anonymous and read-only. Poll on the cache lifetime in the response. On a 429, honour Retry-After and do not retry in parallel.

## 5. Disclaimer

The site is provided as it is. We do not guarantee that the content is complete, accurate, or continuously available.
