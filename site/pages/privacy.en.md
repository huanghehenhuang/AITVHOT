Lead:

> You do not need an account to use this site. We only handle what the site needs to run and to process feedback, and we do not sell personal information.

## 1. Data stored in the browser

Saved items, read marks, appearance, recent searches (the words you searched, at most 10), changelog read state and a feedback draft stay in this browser. List position, scroll position and expanded state on the way back live only in this tab's session storage and are cleared when the tab closes. None of that is sent to the server. Clearing browser data removes it, and it does not sync to another device. Saved items, read marks and appearance can be exported and imported on the Saved page.

## 2. Feedback

What you submit on the feedback page, an optional email, the address of the page you were on, and any screenshot you attach are stored on the server so we can handle the feedback. If the site is configured with an internal Feishu group, feedback is forwarded there; after a screenshot is uploaded to Feishu it is not kept on the server. To limit abuse, the server stores an identifier derived from the network address and browser class that cannot be reversed, used for rate limits and for blocking abusive sources.

## 3. Server and network logs

This software does not collect visitor statistics by default. Your server, reverse proxy or CDN may record access logs under its own configuration (for example IP address, time, page address, browser). State here which services you actually use and how long those logs are kept.

## 4. Third-party content

The site shows summaries of, and links to, third-party originals. After you open an original link you are on that site, under its privacy policy.

## 5. Contact

State how to reach you, and how someone can ask to see, correct or delete feedback they sent.
